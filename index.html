Промпт для Claude / ChatGPT 
Ти — senior frontend-дизайнер. Зроби інтерактивний калькулятор вартості для вбудовування на сайт клієнта.

— НІША: [ВПИШИ НІШУ]

— КОЛЬОРИ: [ВПИШИ 1–2 КОЛЬОРИ СЛОВАМИ АБО КОДОМ КОЛЬОРУ, напр. «бірюзовий на світлому фоні» чи код «#12B3A2 + білий». Лишиш порожнім — підбереться палітра під нішу сама]

ТИП КАЛЬКУЛЯТОРА: авто
(Claude сам визначає тип за нішею. Або впиши літеру, щоб задати вручну:
— A — параметричний: ставка × обсяг + опції (клінінг, ремонт, друк, перевезення)
— B — пакетний/конфігуратор: збери склад або вибери тариф (веб, event, фото, підписки)
— C — множник × кількість із порогами знижок (оренда, переклад, реклама, опт)
— D — вигода/окупність ROI: «скільки зекономите / за скільки окупиться» (сонячні панелі, автоматизація, B2B)
— E — фінансовий/розстрочка: платіж на місяць (авто, нерухомість, техніка))

Все інше визнач і добудуй сам під цю нішу й обраний тип:

─────────────────────────────────────────────
1. ЛОГІКА ЦІНИ (за типом):
─────────────────────────────────────────────
— A: базова ставка × обсяг + модифікатори + доплати за опції.
— B: набір блоків або рівнів-тарифів; ціна = сума обраного.
— C: кількість × ставка за одиницю, з порогами знижки на об'ємі.
— D: людина вводить свої поточні цифри → показуй економію / строк окупності.
— E: сума × ставка × строк → платіж на місяць.
Придумай реалістичні числа у гривнях (₴). Задай розумну мінімальну суму (де це доречно за типом).

─────────────────────────────────────────────
2. ЕЛЕМЕНТИ КЕРУВАННЯ:
─────────────────────────────────────────────
Під кожен параметр — правильний контрол:
— вибір з варіантів → сегментовані картки (показуй ставку або різницю);
— число в діапазоні → слайдер із живою цифрою;
— кількість → степер (− значення +);
— опції так/ні → чіпи-перемикачі з ціною поруч;
— ввід власних цифр (для типу D) → чисті поля з підписами.

─────────────────────────────────────────────
3. РЕЗУЛЬТАТ З'ЯВЛЯЄТЬСЯ ТІЛЬКИ ПІСЛЯ ВВОДУ (важливо!):
─────────────────────────────────────────────
На старті ціну НЕ показуй. Нічого не має бути обрано за замовчуванням так, щоб одразу малювалася готова сума. Спочатку в блоці результату — нейтральний стан-заклик («Оберіть параметри, щоб побачити вартість» і тире/плейсхолдер замість цифри). Велика цифра плавно З'ЯВЛЯЄТЬСЯ й анімується лише ПІСЛЯ того, як користувач зробив перший вибір або ввів свої дані. Далі при кожній зміні — плавний перерахунок із розбивкою по рядках. Для A/B/C/E це ціна або платіж, для D — економія / окупність. Якщо в ніші краще зачепити, а не показувати точну суму — показуй «від X ₴», а точну давай після контакту.

─────────────────────────────────────────────
4. ЗАЯВКА:
─────────────────────────────────────────────
Кнопка «Отримати точний прорахунок» → форма (ім'я + телефон) → екран подяки з підсумком розрахунку. Телефон — тільки український формат +380 з авто-маскою та валідацією, жодних російських номерів. У JS залиш коментар-місце для відправки заявки в CRM / Telegram / Google Sheets.

─────────────────────────────────────────────
5. ДИЗАЙН І КОМПОЗИЦІЯ:
─────────────────────────────────────────────
Композиція вирівняна ПО ЦЕНТРУ сторінки й візуально збалансована — не зсунута вліво, без порожнього боку. Заголовок і підзаголовок — по центру. Сам калькулятор — акуратний центрований блок (можна дві врівноважені колонки однакової ваги, але НЕ вузька панель приліплена збоку). Використай задані КОЛЬОРИ як основу палітри (або підбери під нішу, якщо не задані). Типографіка — під характер ніші, не шаблонна. Одна яскрава фішка — жива цифра результату; усе навколо чисте й спокійне. Адаптив під мобільний, видимий фокус клавіатури, доступність.

─────────────────────────────────────────────
6. МОВА І ВАЛЮТА:
─────────────────────────────────────────────
Весь текст — українською. Валюта — виключно гривні (₴). Копірайт пиши від болю клієнта цієї ніші, короткими зрозумілими фразами, без «води».

─────────────────────────────────────────────
ФОРМАТ ВІДДАЧІ:
─────────────────────────────────────────────
Один самодостатній HTML-файл (HTML + CSS + JS в одному файлі, шрифти з Google Fonts із кирилицею). Нічого не питай — одразу зроби найкращий варіант.
